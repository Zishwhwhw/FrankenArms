# Инструкции для Codex: Unity-проект

Перед работой прочитай `PROJECT_CONTEXT.md`, `SESSION_HANDOFF.md`, `DECISIONS.md` и `FrankenArms_GDD_RU.html`.

## Контекст

- Владелец разрабатывает игру Unity и продолжает работу между Mac и Windows.
- Unity Editor и Unity CLI предполагаются на Windows-ноутбуке.
- Старый проект служит референсом. Новый GDD имеет приоритет над старой реализацией.
- Ссылка на актуальный репозиторий должна быть записана в `REPOSITORY.md`.

## Рабочий процесс

1. Не делать широких переработок без сверки с GDD.
2. Делать небольшие, понятные изменения; после них проверять Console/компиляцию и, когда возможно, Play Mode.
3. До рискованной правки создать Git commit или явно записать checkpoint.
4. После работы обновить `SESSION_HANDOFF.md`: сделано, проверено, проблема/риск, следующий шаг.
5. Не коммитить Unity-generated папки: `Library/`, `Temp/`, `Logs/`, `UserSettings/`.
6. Для больших бинарных ассетов использовать Git LFS.

## Безопасность

Не запрашивать и не записывать пароли, коды 2FA, токены или ключи в документы проекта, Git или чат.
